# Neovim Starter Guide

A complete, personal macOS terminal and Neovim build using Zsh, Oh My Zsh, Powerlevel10k, Homebrew, tmux, Lazy.nvim, Mason, LSP, and Treesitter.

This is my independent build, adapted from [Josean Martinez's dev-environment-files](https://github.com/josean-dev/dev-environment-files). It is not an official Josean repository or release.

## Start here

1. Read [the system overview](docs/01-overview.md).
2. Follow [the installation guide](docs/02-installation.md).
3. Use [the folder structure](docs/08-neovim-folder-structure.md) to understand the config.
4. Keep [the command reference](reference/commands.md) and [keybinding cheat sheet](reference/keybindings.md) nearby.
5. Use [troubleshooting](docs/18-troubleshooting.md) when something fails.
