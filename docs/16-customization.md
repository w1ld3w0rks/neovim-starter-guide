# Customization

Edit options in `lua/josean/core/options.lua`, keymaps in `lua/josean/core/keymaps.lua`, and feature behavior in `lua/josean/plugins/`. Change one layer at a time and restart Neovim after structural changes.

Keep personal changes in this repository rather than editing installed plugin files under `~/.local/share/nvim/lazy/`. Use `lazy-lock.json` to record versions and commit meaningful configuration changes.
