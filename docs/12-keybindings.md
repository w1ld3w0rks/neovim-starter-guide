# Keybindings

Leader is Space. First return to Normal mode with `Esc`.

| Keys | Action |
|---|---|
| `i`, `Esc`, `:w`, `:q`, `:wq` | Edit, normal mode, save, quit |
| `Space sv`, `Space sh` | Vertical/horizontal split |
| `Space se`, `Space sx` | Equalize/close split |
| `Space to`, `tx`, `tn`, `tp`, `tf` | Tab actions |
| `Space nh` | Clear search highlight |
| `jk` | Exit Insert mode |
| `Ctrl-h/j/k/l` | Navigate Neovim/tmux panes |
| `:NvimTreeToggle` | Toggle file tree |
| `:Telescope find_files` | Find files |
| `:Telescope live_grep` | Search text |
