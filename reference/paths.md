# Path reference

| Path | Role |
|---|---|
| `~/.zshrc` | Zsh startup and aliases |
| `~/.p10k.zsh` | Powerlevel10k prompt |
| `~/.tmux.conf` | tmux settings and plugins |
| `~/.tmux/plugins/tpm` | TPM |
| `~/.config/nvim` | Active Neovim configuration |
| `~/.local/share/nvim/lazy` | Lazy.nvim plugin data |
| `~/.config/nvim/lazy-lock.json` | Plugin lockfile |
| `~/.config/nvim.before-josean.20261031005256` | Previous Neovim backup |
