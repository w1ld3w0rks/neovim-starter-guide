# Plugin reference

| Area | Configuration |
|---|---|
| Plugin manager | `lua/josean/lazy.lua` |
| Completion/snippets | `nvim-cmp.lua`, LuaSnip |
| LSP/tools | `lua/josean/plugins/lsp/`, Mason |
| Treesitter | `treesitter.lua` |
| Files/search | `nvim-tree.lua`, `telescope.lua` |
| UI | `colorscheme.lua`, `lualine.lua`, `bufferline.lua` |
| Git | `gitsigns.lua`, `lazygit.lua` |
| Editing | `autopairs.lua`, `surround.lua`, `substitute.lua` |
| Workflow | `auto-session.lua`, `vim-maximizer.lua`, tmux navigator |

See the [upstream plugin documentation](https://github.com/josean-dev/dev-environment-files) for the adapted foundation.
