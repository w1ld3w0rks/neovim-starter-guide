# Keybinding cheat sheet

Leader: Space. `Space sv/sh` splits; `Space se/sx` equalizes/closes; `Space to/tx/tn/tp/tf` manages tabs; `Space nh` clears highlights; `jk` exits Insert mode; `Ctrl-h/j/k/l` navigates Neovim and tmux panes.

File tree: `Enter`, `a`, `d`, `r`, `R`, `q`. Telescope: `:Telescope find_files`, `:Telescope live_grep`. LSP: `gd`, `K`, `gr`.
