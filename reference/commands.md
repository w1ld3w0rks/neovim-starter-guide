# Command reference

## Shell

`nvim .` opens a project; `tmux` starts a session; `gs` shows Git status; `reload` reloads Zsh; `brewup` updates Homebrew.

## Neovim

`:w`, `:q`, `:Lazy`, `:Mason`, `:LspInfo`, `:checkhealth`, `:TSUpdate`, `:NvimTreeToggle`, `:Telescope find_files`, and `:Telescope live_grep`.

## tmux

`Ctrl-a |`, `Ctrl-a -`, `Ctrl-a c`, `Ctrl-a r`, and `Ctrl-a h/j/k/l`.
